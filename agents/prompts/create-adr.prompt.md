# Create ADR Prompt

Record an architecture decision in `docs/adr/`.

Workflow reference:

- `.agents/skills/create-adr/SKILL.md`

Requirements:

- Create an ADR only when the decision is hard to reverse, surprising without
  context, and the result of a real trade-off.
- Match the existing ADR naming and format.
- List the alternatives and why they were rejected.
- Ask before writing when the format or scope is unclear.

Output format:

1. Decision summary
1. Three-condition check
1. Alternatives considered
1. Proposed ADR text or record path
1. Index or link updates
