# Create EDD Prompt

Draft or expand an engineering design document for this repository.

Workflow reference:

- `.agents/skills/create-edd/SKILL.md`

Requirements:

- Use `.agents/skills/conduct-interview/SKILL.md` to resolve open questions
  before drafting.
- Write prose in ASD-STE100 per `.agents/references/asd-ste100.reference.md`.
- Write behavioral contracts and done criteria in EARS per
  `.agents/references/ears.reference.md`.
- Follow `.agents/skills/create-edd/edd-template.md`.
- Compare options when a decision is open.
- Do not invent paths, versions, or behavior.

Output format:

1. Document draft or path
1. Current and target design summary
1. Options and recommendation
1. Risks and open questions
1. Standards applied
