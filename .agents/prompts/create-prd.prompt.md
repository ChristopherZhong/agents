# Create PRD Prompt

Draft or expand a product requirements document for this repository.

Workflow reference:

- `.agents/skills/create-prd/SKILL.md`

Requirements:

- Use `.agents/skills/conduct-interview/SKILL.md` to resolve open questions
  before drafting.
- Write prose in ASD-STE100 per `.agents/references/asd-ste100.reference.md`.
- Write functional requirements and acceptance criteria in EARS per
  `.agents/references/ears.reference.md`.
- Follow `.agents/skills/create-prd/prd-template.md`.
- Do not invent paths, versions, or behavior.

Output format:

1. Document draft or path
1. Goals and non-goals
1. Open questions
1. Standards applied
